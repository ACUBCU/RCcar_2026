## 주제: AutoCar Prime nx를 사용한 공간 투영

2026년 7월 13일 ~ 17일

## 개인 역할 분담 및 실행

| 담당 | 역할 | 실행 내용 |
| --- | --- | --- |
| 이동헌 | PM / 아키텍처 | 전체 일정 관리, 문서 작성, 주행 로직 구현 |
| 신동수 | 카메라 비전 | 데이터 수집 및 전처리, 모델 학습 및 평가, 웹뷰 화면 제작 |

## 과제 목표

* AutoCar Prime nx의 2D 라이다(RPLiDAR)와 카메라(Sony IMX219)를 사용해 공간 탐지와 주행을 할 수 있는 시스템을 만든다.
* 라이다 센서를 주 센서로 활용하여 공간을 탐색하고, 전방위 빈 공간 중 가장 개방된 영역을 스스로 판단하여 주행하는 자율 탐색 알고리즘을 구현한다.
* 카메라를 보조 센서로 활용하여 라이다 스캔 평면을 벗어나는 주행 불가 구간을 인지하고, 발견 즉시 우회 주행 명령을 내리는 로직을 구현한다.
* AutoCar(Flask 서버)와 관제용 노트북(pywebview 클라이언트)을 동일한 무선 네트워크(Wi-Fi)로 연결하여 원격 제어 환경을 구축한다.
* pywebview 기반의 데스크톱 대시보드에 HTML5 Canvas를 활용하여, 라이다가 스캔한 점유 격자 지도(Occupancy Grid Map)가 실시간으로 확장 및 렌더링되는 동적 UI를 구현한다.

## 수행 계획서

* 시스템을 라이다 데이터 처리부, 카메라 비전 처리부, 데이터 동기화 및 제어부, 사용자 관제 대시보드로 분리하여 설계한다.
* 라이다 처리부는 라이다로 수집된 데이터를 웹뷰화면에 표시한다. 전방 경로가 막혔을 경우, 미리 스캔된 좌/우 공간의 여유를 비교하여 회전 방향을 스스로 결정한다.
* 주행 환경에 있는 요소들을 가지고 주행이 가능한지 불가능 한지를 alexnet 모델을 전이학습시켜 사용한다.
* 카메라 비전 처리부는 학습시킨 모델을 가지고 라이다의 탐지영역에 없는 주행 불가능 영역을 탐지해 주행을 우선적으로 제어하게 한다.
* 카메라 비전 처리부에서 장애물이나 주행 불가 영역이 감지되는 즉시 라이다의 조향 명령을 무시하고 시스템에 우회 주행을 명령하는 인터럽트 방식을 적용한다.
* Flask-SocketIO 서버는 라이다의 스캔 속도에 동기화하여 초당 10회 주기로 2D 로컬 맵 배열 데이터와 차량 상태, 카메라 우회 경고 신호를 노트북 대시보드로 푸시(Push)한다.
* 관제용 노트북의 pywebview 대시보드는 수신된 배열 데이터를 Canvas에 즉각적으로 덧그려, 차량의 시야가 닿는 빈 공간과 벽의 윤곽이 드러나는 자율 탐색 과정을 실시간으로 렌더링한다.

## 시행 목적

본 프로젝트의 목적은 센서의 물리적 한계를 상호 보완하는 인지 기술과 로컬 네트워크 기반의 실시간 웹소켓 통신을 결합하여 AutoCar Prime nx의 주행 안정성 및 관제 효율을 확보하는 것이다.

2D 라이다를 통해 스스로 빈 공간을 파악하며 맵을 확장해 나가는 실시간 탐색 능력을 구현한다. 동시에 카메라는 라이다가 놓칠 수 있는 바닥의 장애물을 필터링하여 치명적 충돌을 방지한다. 에지 디바이스(Jetson NX)의 컴퓨팅 자원을 탐색(라이다)과 위험 감지 및 우회(카메라)로 효율적으로 분배하며, 물리적으로 분리된 장비 간의 지연 없는 양방향 통신(WebSocket) 아키텍처 설계 경험을 얻는다.

## 사용 장비

* AutoCar Prime nx
* RPLiDAR
* Sony IMX219
* 관제 대시보드 구동 및 렌더링용 노트북
* 로컬 네트워크 구성용 무선 라우터(공유기) 1대

## 최종 시연 시나리오

1. 무선 라우터를 통해 AutoCar Prime nx와 노트북을 동일한 로컬 네트워크에 연결하고 각 시스템(Flask 서버, pywebview 대시보드)을 구동한다.
2. AutoCar를 작동시켜 주행을 시작할 준비를 한다.
3. 대시보드에서 '탐색 시작' API 명령을 전송하면, AutoCar가 스스로 빈 공간을 향해 주행을 시작한다.
4. 차량이 전진 및 방향 전환을 수행함에 따라, pywebview 화면의 Canvas 상에 보이지 않던 공간(코너 너머 등)의 2D 지도가 SocketIO 스트리밍을 통해 실시간 확장 렌더링되는 과정을 시연한다.
5. 방향을 전환하여 진입한 새로운 경로 상에 배치된 소형 장애물이나 주행 불가 영역에 접근한다.
6. 카메라가 해당 영역을 인지하고, 차량이 우회하여 주행한다.
7. 탐색이 끝나고 화면에 AutoCar가 탐색한 영역이 투영되어 표시된다.

## 기대 효과

* 2D 라이다와 카메라의 역할 분담을 통해 연산 자원을 절약하면서도 사각지대를 해소하여 사고 발생률을 최소화한다.
* Flask-SocketIO 기반의 저지연 통신 구조를 확립하여, 대용량 맵핑 데이터의 실시간 스트리밍 관제 시스템 성능을 극대화한다.
* 독립적 센서 제어 처리, 자율 맵핑 알고리즘 구동, 로컬 네트워크 통신, pywebview 데스크톱 UI 렌더링까지 아우르는 자율주행 풀스택 통합 역량을 확보한다.
